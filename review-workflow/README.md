# Review workflow demo

This small review workflow has domain types, commands, notification text,
a reminder worker, and view helpers. Each module can be read on its own.

The demo branch changes three concepts across the workflow. Review one
change, then use the inline suggestion to review its related changes.
The inbox limit and empty-state copy are separate review decisions.

The base branch contains the complete starting application so the pull
request shows edits to existing code, with unchanged context between hunks.
